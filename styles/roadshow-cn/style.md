# roadshow-cn：竞赛路演（挑战杯 / 互联网+ / 创青春）

> 用户认可的基准（2026-11-10，「非常标准，perfect」）。归纳自两份国奖作品：探旅中轴（2025 挑战杯专项赛）、石破天金（2024 中国国际大学生创业大赛）。两份都是路演类，还没有学术答辩类的样本。石破天金只看到了封面，以及文件里的字体、色值和素材图。

## 适用

竞赛路演、项目答辩、创业比赛。听众是评委，他们默认「塞得满、做得细」才叫用心。和西方 deck 的极简留白是两条路。

## 一句话

深海军蓝打底，金色点睛，信息塞满，每页都有「设计感部件」。风格接近政务宣传和科技展会。

## 设计靠什么撑起来

| 手法 | 做法 |
|---|---|
| **色彩比例** | 蓝占九成、金占一成。金色不铺面，只给字和细线。深蓝到浅蓝的渐变很普遍，几乎没有纯平涂 |
| **双层标题** | 上面一行白色小字，下面一行金色大字，例如「人工巡园 / **发现太晚** / 肉眼可见 = 已扩散」 |
| **书法标题** | 封面和结尾用行楷或特粗展示字体，「国风」靠它体现 |
| **固定顶栏** | 深蓝通栏约占页高 11%：左边是 `»` 加页面标题，右边是章节导航，当前章节放大 |
| **关键词标金** | 一段正文里 2 到 4 处金色短语，相当于给评委划好重点 |
| **复杂结构图** | 等轴测堆叠、节点连线图、箭头链、雷达图，都见 `guide/shapes.md` |
| **证据墙** | 政策、专利、证书叠放，盖红章，证明「有依据」「做出来了」 |
| **装饰部件** | 胶囊标签、斜体标签条、发光光效、科技底纹、国风纹样、虚线框、底部飘带 |

## 页型

封面、背景、痛点、方案、技术、产品、商业、团队、展望、结尾。样板里有封面、痛点、核心技术、实验验证这 4 页。

- 封面和结尾同构：全幅题材图加深蓝蒙层，书法大标题，金色副标题横条，左上角是赛事名。
- 痛点页：三栏，半透明线稿或人物照做底，双层标题，金色数字条，底部飘带写核心矛盾。
- 技术页信息最密：架构图、网络结构图、公式、创新点同时出现。

## 可验收条目

- 【场景】只适用于本场景；【通用】可以迁移到其他场景；【参数】原则通用，阈值随场景变。

| # | 条目 | 类别 |
|---|---|---|
| P1 | 主色深海军蓝，强调色金；整套色相不超过「蓝、金、白、浅灰」，再加一个题材色 | 场景 |
| P2 | 内容页有统一顶栏：标题加章节导航，当前章节高亮 | 通用 |
| P3 | 封面和结尾同构；封面标题用书法或特粗展示字体，副标题放在色条上 | 场景 |
| P4 | 每页至少一个真实图像：照片、截图、样机或图表。没有纯文字页 | 通用 |
| P5 | 每页 2 到 4 处金色或加粗关键词 | 参数 |
| P6 | 关键数字放大成为视觉焦点 | 通用 |
| P7 | 每页至少一种装饰部件；整套 deck 只用一套部件语言，不混搭 | 通用 |
| P8 | 背景不是纯色：浅色渐变、底纹或半透明图片 | 通用 |
| P9 | 内容页的文字和图形填满七成以上版面 | 参数 |
| P10 | 同类页型保持同一版式 | 参数 |

## 改主题时

颜色全部可配置：
- 角色变量 `--c-*` 在 `tokens.css`；
- 本分支的细分色阶 `--rc-*` 在 `components.css` 顶部；
- 本页可调颜色 `--pg-*` 在页面 `<style>` 顶部。

题材插画（茶叶、扫描环、远山、线稿）随项目替换，颜色不进主题。

换赛事（比如互联网+偏商业）时，可以把金色换成更亮的黄，再加科技青点缀。**这条是暂定的**：依据只有石破天金的封面和色值，等看到更多页面再确认。蓝金骨架保持不变。

## 字体

行楷 `Xingkai SC`、魏碑 `Weibei SC`、数字 `DIN Alternate`。苹方最粗只到 Semibold，特粗标题可以考虑兰亭特黑 `FZLTTHK--GBK1-0`。但改了就会破坏已认可的基准，要先问用户。

## 反面

完整清单见 `guide/anti-patterns.md`。本场景里 N4（信息少）和 N5（西式极简）都算缺陷。
